# Практикум по C#

Консольное приложение с заданиями по C#. Все три уровня: задания 1–50.

## Запуск

```bash
dotnet build
dotnet run --project CSharpPracticum/CSharpPracticum/CSharpPracticum.csproj
```

Тесты библиотеки (задание 45): `dotnet test CSharpPracticum/CSharpPracticum.Tests/CSharpPracticum.Tests.csproj`.

В главном меню выберите уровень, затем номер задания. `0` или `q` — назад/выход.

## Заметки

**Уровень 1.** Повторил ввод, условия, циклы, массивы, строки и словари. Сложнее было сделать два алгоритма сортировки и аккуратно посчитать возраст.

**Уровень 2.** Попробовал интерфейсы, наследование, обобщения, исключения, файлы и LINQ. В задании 22 обычный `int[]` нельзя перегрузить одновременно с `params int[]`, поэтому вторая перегрузка принимает `IEnumerable<int>`.

**Уровень 3.** Попробовал HashSet, Dictionary, yield return, async/await и отмену задач. Сделал список дел с JSON и небольшую библиотеку с тестами. В Git потренировался со stash, rebase, тегами, reflog и bisect. С заданиями всё получилось, проблем не возникло.


**Дополнительно к заданию 35.** Попробовал GitHub Actions: настроил автоматическую сборку и простую проверку меню. После проверки удалил workflow, потому что он не входит в требования практикума. Подробности есть в `git-notes.md`.
