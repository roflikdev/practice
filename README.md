# Практикум по C#

Консольное приложение с заданиями по C#. Первые два уровня: задания 1–35.

## Запуск

```bash
dotnet build
dotnet run --project CSharpPracticum/CSharpPracticum/CSharpPracticum.csproj
```

В главном меню выберите уровень, затем номер задания. `0` или `q` — назад/выход.
